### 使用说明

1. Install Ruby (and Bundler)

```bash
sudo apt-get install ruby-full
or
brew install ruby
```

2. Install Dependencies

```bash
bundle install

bundle exec jekyll build
bundle exec jekyll serve
```

3. Open URL

URL: `http://127.0.0.1:4000/academic/`
